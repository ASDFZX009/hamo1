# Hamo — Flask + Tailwind + Supabase Project

## 📁 Folder Structure

```
Hamo/
├── backend/
│   ├── app.py              # Flask app with REST API
│   ├── database.py         # Supabase client setup
│   ├── requirements.txt    # Python dependencies
│   └── .env.example        # Sample environment variables
├── database/
│   └── schema.sql          # SQL to create the users table in Supabase
└── frontend/
    ├── index.html          # Main UI (user form + table)
    ├── package.json        # Node/Tailwind config
    ├── tailwind.config.js  # Tailwind content paths
    ├── src/
    │   └── input.css       # Tailwind entry CSS
    └── css/
        └── output.css      # Generated by Tailwind (gitignore this)
```

---

## 🗄️ Database Setup (Supabase)

1. Create a free project at [supabase.com](https://supabase.com)
2. Go to **SQL Editor** and run the contents of `database/schema.sql`
3. Copy your **Project URL** and **Anon Key** from Project Settings → API

---

## ⚙️ Backend Setup (Flask)

```bash
cd backend

# Create & activate virtual environment
python -m venv venv
venv\Scripts\activate   # Windows

# Install dependencies
pip install -r requirements.txt

# Setup environment
copy .env.example .env
# Edit .env with your Supabase URL and Key

# Run the server
python app.py
```

Backend will run at `http://localhost:5000`

---

## 🎨 Frontend Setup (Tailwind)

```bash
cd frontend

# Install Tailwind
npm install

# Build CSS once
npm run build:css

# OR watch for changes during development
npm run watch:css
```

Then open `frontend/index.html` in your browser.

## 🔌 API Endpoints

| Method | Endpoint             | Description         |
|--------|----------------------|---------------------|
| GET    | `/api/users`         | Get all users       |
| GET    | `/api/users/<id>`    | Get user by ID      |
| POST   | `/api/users`         | Create a new user   |
| PUT    | `/api/users/<id>`    | Update a user       |
| DELETE | `/api/users/<id>`    | Delete a user       |

## 🗃️ Users Table Schema

| Column           | Type    | Notes                          |
|------------------|---------|--------------------------------|
| `user_id`        | UUID    | Primary key, auto-generated    |
| `fullname`       | TEXT    | Required                       |
| `age`            | INTEGER | Required, must be > 0          |
| `address`        | TEXT    | Required                       |
| `phone_number`   | TEXT    | Required                       |
| `email`          | TEXT    | Required, must be unique       |
| `shirt_size`     | TEXT    | XS / S / M / L / XL / XXL     |
| `payment_status` | TEXT    | pending / paid / failed        |
| `created_at`     | TIMESTAMPTZ | Auto-set on insert         |
